# Output repository for the dissertation operating modes study

This repository stores the `CADET-RDM` results for the dissertation study on advanced chromatographic operating modes.
The corresponding study code and pinned environment are in the project repository linked below.
The dissertation source is available in the thesis repository linked below; Chapter 6 contains the narrative description and discussion of the reported operating mode studies.

Each simulation run creates a dedicated branch in this output repository.
The results are saved on the respective branch, while `log.tsv` on `main` records metadata that links each output branch to the originating project commit, command, options, and software environment.

Runs with push access can publish CADET-RDM result branches automatically.
Without push access, the calculations can still be reproduced locally from the pinned environment and source state, but result branches remain local or pushing must be disabled.
